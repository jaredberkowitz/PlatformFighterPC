# Shared combat mechanics: inventory

What the engine can already do for a moveset, where it lives, who uses it, its knobs, its limits and the tests that protect it. Read this
before building anything for a new port: if a mechanic is here, reuse it; if it is close, extend it here (and update this file); only if
it is missing, build it, generally, and add a row.

Built from the code at sim version 55 (content schema 3), October 2026, and updated for sim 64 (content schema 4, the Embers' specials) and sim 66 (content schema 5: the Gauntlets' phase 1, with E17, E19, E24 and the `presses` registers) and sim 67 (the Staff's phase 1, with E26 angle types and E27 signed hitstun modifiers; no schema change), sims 67 to 72 (the Gauntlets' phase 2: the shield stun fix, E1 armor, the E11 additions, E21 search boxes, E6 command grabs, E3c no-clank hits, E22 off-edge versions, the `wall` register) and sim 73 (angle type 1 by travel, the Gauntlets' specials' angle types, the Staff's no-clank boxes, get-up attacks at angle 48), and sims 74 to 77 (the Staff's specials: E3a multi-hit piercing projectiles, E10c counter / reflector routing, the barrier's capsule and body fields, `air_max_rise`, counters catching through their own intangibility, the `flick`, `locked` / `lock_x` / `lock_y` registers and the `spawn_at` and `lock` functions, `collision::segment_blocked`; no schema change), and sim 83 (the Greatsword's phase 1: no new mechanic; the throws' several pre-hits and the jab's held repeat noted below), and sim 85 (content schema 6, the Greatsword's phase 2: E9 the gauge and its powered mode, E16 `boost` / `boosting` / `grab` / `boost_add`, E11 `start_speed_y` and `ledge_drop`, E22b `on_land`, E3f `Hitbox::half_height`). "Sword" is the Longsword (class 0, duelist body), "Claws" class 1
(brawler body), "Needles" class 2 (rogue body). File paths are from the repo root. Test names are the `#[test]` function names.

How a move flows (traced): `fighter::update` → `ground` / `airborne` → `start_ground_attack` / `start_air_attack` / `start_special` →
`begin_attack` (state `Attack`, `state_frame` 0, `hit_mask` 0, `charge` 0, script vars cleared on entering `Attack`) → each frame
`fighter::attack` (turn windows, smash charge, rehit, projectile request, script, motion or air physics or ground friction, end of move,
jab chain, ledge grab) → after every fighter has moved, `combat::resolve_hits` (collect, clank, apply), `grab::update`,
`combat::update_projectiles`, `combat::spawn_projectiles` (`sim-core/src/step.rs`).
